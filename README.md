# 🚀 Practice Automation Selenium Tests

Автоматизированный тестовый проект для веб-приложений, разработанный с использованием Python и Selenium.  
Проект создан в рамках практики и демонстрирует навыки построения тестового фреймворка с нуля.

---

## 📌 О проекте

Данный проект представляет собой набор автоматизированных UI-тестов для веб-приложения.  
Основная цель — продемонстрировать навыки автоматизации тестирования, архитектуры тестов и работы с современными инструментами QA.

---

## 🛠️ Стек технологий

- Python
- Selenium WebDriver
- PyTest
- Page Object Model (POM)

---

## ⚙️ Функциональность

- Автоматизация пользовательских сценариев
- Проверка UI элементов
- Работа с браузером через Selenium WebDriver
- Использование паттерна Page Object Model
- Логирование действий тестов
- Подготовка структуры под масштабируемый фреймворк

---

## 🏗️ Архитектура проекта

Проект построен с использованием паттерна **Page Object Model (POM)**, что обеспечивает:

- Переиспользуемость кода
- Удобство поддержки
- Чистую структуру тестов

Пример структуры:

project/
│── pages/ # Page Objects
│── tests/ # Тесты
│── utils/ # Вспомогательные методы
│── conftest.py # Фикстуры PyTest
